# Projeto para a disciplina SSC0119 - Prática em Organização e Arquitetura de Computadores
Este projeto consiste na construção de **instruções para a CPU in-house do ICMC** e na criação de um **jogo a partir de linguagem Assembly**.

## Escopo do projeto
Planejamos programar um plataformer 2D old-school, inspirado no Super Mario Bros. do Nintendo Entertainment System, garantindo que tenhamos um orçamento de hardware o suficiente para implementar o jogo.

## Requisitos
Para um plataformer funcional, precisamos de algumas funcionalidades:
- Movimentação.
- Colisão (Personagem, inimigos, coletáveis).
- **Divisão de Char entre dois espaços** (Necessário pra fluidez pois movimentção em um espaço 40x30 é muito ruim).
- Se tivermos uma maior competência, **aumentar a resolução da tela**.
- Física para pulo/queda, tanto para personagens quanto para bola de fogo (possível que seja reciclável).
- Tempo e pontuação.
- Câmera.
- *Morte*.
